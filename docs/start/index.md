# 脑中的那张地图

出门前查好的路线，到了现场却发现入口封闭。地图依然有用，只是现场多了一条信息，路线需要随之改变。

理解一件事也是如此。每个人都凭所见所闻，在脑中形成一张关于世界如何运作的“地图”。它帮助判断，也可能遗漏事实。理解加深，就是让这张地图更能解释发生的事，并在遇到新事实时修正它。

## 分清事实、猜测和期待

假设一个项目希望让顾客更容易取消订单。可以先写下三句话：

- **事实：** 顾客常向客服询问如何取消订单，有记录可查。
- **猜测：** 取消按钮太小，顾客找不到。
- **期待：** 符合条件的顾客能够自行取消，并知道结果。

询问记录说明有人遇到了困难，却无法证明按钮是原因。下一步应先调查入口、取消规则和反馈，再决定改什么。把猜测当成事实，可能花力气放大了按钮，问题仍然存在。

## 从理解到需求

一句“让取消订单更容易”，可能被理解为调整入口，也可能被理解为增加退款和售后。合作开始时，需要先说清已有事实、待查问题和期待的结果。

AI 调查现状、比较办法，整理成完整提案；人确认目标、范围和取舍。共同确认的内容写成需求，继续指导设计、分工和检查。发现新事实，再判断需要调整做法，还是重新确认原来的目标。

# 脑中的那张地图

出门前查好的路线，到了现场却发现入口封闭。地图依然有用，只是现场多了一条信息，路线也需要随之改变。

理解一件事也是如此。每个人都凭经历和消息，在脑中描画一张关于世界如何运作的“地图”。它帮助判断，却无法囊括现实。理解逐渐加深时，这张地图能更好地解释发生的事、预想可能的结果，也能随着新事实被修正。

“地图”只是比喻。人的思考远比纸上的路线复杂；这里借用它，是为了给下一步思考找一个起点。

## 三种不同的句子

假设一个项目希望让顾客更容易取消订单。关于这件事，可以先写下三句话：

- **有依据的事：** 顾客向客服询问如何取消订单，相关记录可以查到。
- **还在猜的事：** 困难来自取消按钮太小。
- **希望发生的改变：** 符合条件的顾客能够自行取消，并知道结果。

询问记录说明有人遇到了困难，却无法单独证明按钮是原因。按钮大小值得调查；顾客真正需要的结果也许牵涉取消规则或后续反馈。分清这三句话，才能决定下一步该调查什么、承诺什么。

## 从各自的理解，走向共同的方向

一句“让取消订单更容易”，在人心里可能意味着调整入口；AI 则可能把退款、发货状态一并纳入。两种理解都来自同一句话，指向的工作却不同。

合作由此开始：把事实说清，把猜测标出来，把期待的结果讲明白。AI 负责调查和提出方案；涉及顾客承诺与风险的选择，由人确认。共同确认的部分，才成为后续工作的方向。

不妨从一件想改变的小事开始，分别写下**已有依据、尚待核实的猜测、希望发生的变化**。暂时空着的一栏，也能成为下一次调查的起点。

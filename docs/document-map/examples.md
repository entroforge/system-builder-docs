# `examples/`：看一套填好的样子

`docs/examples/` 放的是合成样例。有些样例甚至带有自己的 `project/docs/` 子目录，外形很像真实项目；它们用来解释文件怎样相互引用，也供模板和工具检查使用。样例中的 REQ、合同、任务与证据都不属于当前项目。

| 子目录 | 展示什么 |
| --- | --- |
| `shared-model/` | 一份共享数据定义怎样同时被前端、后端和联调合同使用 |
| `dispatch-plan/` | 一项 REQ 的多个任务怎样安排先后与并行 |
| `s7-s9/` | 发现问题、调查、修复和定向复验所需材料的示例形状 |
| `s10/` | 验收与发布审计所用结构化清单的示例形状 |

遇到抽象模板难以理解时，示例可以帮助看清文件之间的关系。回到实际项目后，仍须使用该项目自己的需求、当前状态和检查证据作判断。

# `guides/`：按问题查使用说明

`docs/guides/` 提供安装、操作和背景说明。需要查某件事怎么做时，从这里找入口。

| 文件 | 适合查什么 |
| --- | --- |
| `install.md` | 新项目怎样安装，以及版本和存量项目的边界 |
| `getting-started.md` | 安装后的目录、参与角色与第一次开始工作的基本流程 |
| `engineering-loop.md` | 阶段、状态、文档、运行记录怎样共同运作；需要精确机制时查阅 |
| `concepts.md` | 这套方法中的基础概念与原则 |

实际承诺查 [`requirements/`](./requirements)，当前进度查 `.claude/loop-state.json`。指南说明做法，项目记录保存本轮事实。

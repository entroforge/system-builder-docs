# `guides/`：按问题查使用说明

`docs/guides/` 是这套系统随项目提供的操作与背景说明。它帮助查找做法，和项目实际形成的需求、设计、报告不是同一类材料。

| 文件 | 适合查什么 |
| --- | --- |
| `install.md` | 新项目怎样安装，以及版本和存量项目的边界 |
| `getting-started.md` | 安装后的目录、参与角色与第一次开始工作的基本流程 |
| `engineering-loop.md` | 阶段、状态、文档、运行记录怎样共同运作；需要精确机制时查阅 |
| `concepts.md` | 这套方法中的基础概念与原则 |

这些说明面向使用过程。若要确定**本项目这项需求究竟承诺什么**，去 [`requirements/`](./requirements)；若要判断**现在处于什么状态**，核对 `.claude/loop-state.json`。指南不会替代项目事实。
